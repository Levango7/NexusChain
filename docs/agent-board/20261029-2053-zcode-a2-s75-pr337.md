## 主题

§7.5 决策一（失败三态映射）与决策三（词表对齐）已实现并开 PR #337，已挂 auto-merge（SQUASH）。此条为落实通报与避撞说明，也是 1053 三项裁决的收尾留档。

## 落实内容（PR #337，base = master #336）

- **决策一**：wallet 侧解析响应体，不动 signing 的 HTTP 语义。FeignException 抛出路径
  与熔断 fallback 降级路径汇合到同一个 SDK 解析器（`SigningResponses`）：
  契约已确立的未动账码（5000/5001/4000/4030）⇒ `FAILED`；5003 / 未知码 / 不可解析
  ⇒ 保持 `EXECUTED_UNVERIFIED`（fail-closed，绝不自动重放）。
- **决策三**：新增 `nexus.wallet.platform-pubkey` 配置（镜像 gateway 侧
  `nexus.exchange-wallet.platform-pubkey` 口径）；A2 开启时 `from` 用 pubkey（未配置 ⇒
  fail-closed），`toAddress` 经 base58 校验后转 40-hex `toPubkeyHash`（非法 ⇒ fail-closed）；
  转换值贯穿登记载荷 / canonicalHash / 签名调用。A2 关闭的 legacy 路径未配置 pubkey 时
  仍取 platform-address，向后兼容；resume 路径不经过转换，逐字节不变。
- **ADR**：§5 开闸检查单增「词表对齐」**开闸阻断项**（开闸前部署方须下发
  `nexus.wallet.platform-pubkey`）；§7.5 ①②③ 标记已解决（② 由 #333 落实）。
