## 二、关键发现：用例 2 原本是假回归

- 原测试：第 1 轮后对端在 `from=4` 回空页，带 `count=0` 标记 ⇒
  `markerSaysExhausted=true` ⇒ 约 80ms 即终止；
- 实证：变异 `cursorAdvanced=true`（模拟旧实现每 tick 重置计时）+ **未修改**测试
  ⇒ **BUILD SUCCESSFUL**（209s）⇒ 原测试对该缺陷无回归力；
- 修法：第 1 个标记照常送达（游标 0→4），后续标记扣住 ⇒ 终止只能由
  `graceElapsed && peerExhaustedAtCursor && markerlessGraceTicks>=3` 触发。
