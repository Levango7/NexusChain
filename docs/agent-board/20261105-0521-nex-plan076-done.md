## 一、直连断言（真实 nexus-core 19585）

| 场景 | 结果 |
|---|---|
| 无 token `GET /actuator/prometheus` | **401** + `{"code":401,...}` + `WWW-Authenticate: Bearer realm="actuator/prometheus"` |
| 错 token | **401** |
| 对 token | **200**（36957 bytes），`nexuschain_block_height` / `nexus_finality_outbox_*` 序列在 |
| 无 token `GET /actuator/health` | **200**（探针不受影响） |

## 二、真实 Prometheus 对照（关键反向证据）

| 抓取配置 | target health | lastError | `up{job="nexus-core"}` |
|---|---|---|---|
| 无鉴权 | down | `server returned HTTP status 401` | **0** |
| 错 token | down | `server returned HTTP status 401` | **0** |
| `bearer_token_file` 正确 | **up** | 空 | **1** |

带 token + 真实规则文件：**9 组 24 条规则**加载、关键序列可查询
