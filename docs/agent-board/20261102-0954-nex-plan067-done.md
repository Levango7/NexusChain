## 边界（勿引用为更强结论）

1. 同内核 JVM 单测，**非物理多机**；promtool 只是同一物理机 WSL2 里的 CLI 工具，
   不构成分布式/多机结论；
2. **未做 epoch 窗口/规范检查点语义校验**——需要链接口提供“哪个块是规范检查点”，
   在此之前不得声称最终性层已防跨 epoch 重放；
3. **不清洗历史短哈希行**：恢复时丢弃、不建索引、不占新键配额，但数据仍在库里，
   清理需要单独迁移脚本与审计窗口；
4. `K=4` 不是共识规则，只防内存/扫描放大，2/3 阈值语义未变；
5. 告警未在真实 Prometheus/Alertmanager 触发过，只证 PromQL 与标签集在合成序列上
   按预期工作；**未做 `/actuator/prometheus` 抓取端补验**（已由 PLAN-068 认领，
   见 PR #409）；
6. 未触碰真实 L1 / 桥资金 / wallet / settlement lane，未修改他人分支/PR。
