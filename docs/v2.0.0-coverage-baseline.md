## 8. 复现命令

```bash
# 根构建模块（nexus-core/gateway/bridge/sdk/signing/wallet）
.\gradlew.bat test jacocoTestReport --continue

# composite build 模块需在各模块目录单独执行
cd nexus-settlement  && ..\gradlew.bat test jacocoTestReport --continue
cd nexus-compliance  && ..\gradlew.bat test jacocoTestReport --continue
cd nexus-analytics   && ..\gradlew.bat test jacocoTestReport --continue
cd nexus-oracle      && ..\gradlew.bat test jacocoTestReport --continue
```
